## Quick Reference

### Platform-Specific Content Formats

| Platform        | Content Type       | Length Limit         | Key Features                       | Engagement Strategy     |
| --------------- | ------------------ | -------------------- | ---------------------------------- | ----------------------- |
| **LinkedIn**    | Professional posts | 3000 chars           | Text + carousel, industry insights | Professional discussion |
| **Instagram**   | Visual content     | 30s video, 10 images | Reels, carousels, quotes           | Visual storytelling     |
| **X (Twitter)** | Thread series      | 280 chars/tweet      | Multi-tweet threads, hashtags      | Viral tweet storms      |
| **Facebook**    | Stories            | 20s per story        | Interactive, engaging visuals      | Community interaction   |

### Content Transformation Frameworks

1. **Expert Insights Extraction** - Identify key takeaways from interviews and articles
2. **Viral Hook Creation** - Develop attention-grabbing opening content
3. **Platform Format Adaptation** - Optimize content for each platform's unique style
4. **Engagement Element Addition** - Add questions, polls, calls-to-action
5. **Visual Storytelling Enhancement** - Create compelling narratives and graphics

### Engagement Optimization Techniques

1. **Question-Based Content** - Encourage comments and discussion
2. **Behind-the-Scenes Content** - Share process and creation stories
3. **Interactive Elements** - Polls, quizzes, and engagement prompts
4. **Hashtag Strategy** - Research and optimize hashtag combinations
5. **Timing Optimization** - Schedule posts for maximum audience reach

### ContentFlow Agent Coordination

- **Rocket Integration** - Transform SEO insights into social media hooks
- **Connect Processing** - Convert interview stories into engaging social content
- **Forge Coordination** - Adapt multi-format content for social platforms
- **Validator Implementation** - Only transform quality-approved content
- **Pipeline Integration** - Coordinate social publishing with distribution system

### Viral Content Creation Principles

1. **Authenticity First** - Preserve human elements from original interviews
2. **Platform Native Content** - Create content that feels native to each platform
3. **Engagement Focused** - Optimize for likes, shares, comments over reach
4. **Storytelling Priority** - Use narrative techniques to maximize memorability
5. **Community Building** - Create content that fosters ongoing engagement
