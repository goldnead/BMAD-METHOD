# Pillar Page Template

**Format:** Web/Blog (Comprehensive Resource)
**Length:** 3000-5000+ words
**Purpose:** Topic authority hub that ranks for broad, high-volume keywords
**Tone:** Authoritative, comprehensive, evergreen

---

## What is a Pillar Page?

A pillar page is a comprehensive resource that:

- Covers a broad topic in depth
- Links to related cluster articles (sub-topics)
- Acts as the SEO hub for a topic cluster
- Ranks for high-volume, competitive keywords
- Stays evergreen (updated regularly)

**Example Topic Clusters:**

```
PILLAR: "Content Marketing Strategie"
  ├── Cluster: "Content Audit durchführen"
  ├── Cluster: "Content Kalender erstellen"
  ├── Cluster: "SEO Content optimieren"
  └── Cluster: "Content Distribution Kanäle"

PILLAR: "Email Marketing für Coaches"
  ├── Cluster: "Newsletter Aufbau"
  ├── Cluster: "Email Segmentierung"
  ├── Cluster: "Lead Magnets erstellen"
  └── Cluster: "Email Automation Setup"
```

## Pillar Page Structure

### 1. SEO Meta Data

#### Meta Title (50-60 characters)

**Format:** [Broad Keyword] – Der komplette Guide [Year]

**Examples:**

- "Content Marketing Strategie – Der komplette Guide 2025"
- "Email Marketing für Coaches: Alles was du wissen musst"

**Rules:**

- Include year (update annually!)
- Broad, high-volume keyword
- Promise comprehensiveness

#### Meta Description (150-160 characters)

**Format:** [Comprehensive promise] + [What they'll learn] + [Why you're the expert]

**Example:**
"Der ultimative Content Marketing Guide: Von Strategie über Produktion bis Distribution.
Mit Frameworks, Templates und Praxisbeispielen aus 100+ Projekten."

#### Focus Keyword

**Primary:** Broad, high-volume keyword (e.g., "Content Marketing Strategie")
**Secondary:** 4-6 related broader terms (e.g., "Content Strategie", "Content Planning", "Content Distribution")

#### URL Slug

**Format:** `/blog/{broad-keyword}` or `/{broad-keyword}`

**Example:** `/content-marketing-strategie`

**Rules:**

- Short and memorable
- Broad keyword
- Consider using root path for main pillars

```
- What to avoid
- Troubleshooting

### H3: Advanced Tips
- Pro-level insights
- Optimization strategies

[🔗 Link to detailed cluster article]
→ "Für einen deep-dive in [subtopic], lies meinen kompletten Guide:
   [Cluster Article Title with descriptive anchor text]"
```

---

#### Content Depth Guidelines

**Coverage Spectrum:**

```
Pillar Page: 70% depth
  → Covers all aspects but not exhaustive on each

Cluster Articles: 100% depth
  → Exhaustive coverage of one specific aspect
```

**Balance:**

- Comprehensive enough to be useful standalone
- Broad enough to cover full topic landscape
- Deep enough on essentials
- Links to clusters for advanced/detailed coverage

---

#### Visual Content Requirements

**Essential Visuals:**

- Hero image (professional, branded)
- Topic map/cluster diagram (show how everything connects)
- Process flowcharts (2-3 minimum)
- Framework diagrams (visual models)
- Data visualizations (if including statistics)
- Screenshots (for tool recommendations)
- Comparison tables (for alternatives)

**Visual Placement:**

- One major visual every 500-700 words
- Break up text-heavy sections
- Diagrams for complex concepts
- Tables for comparisons

---

#### Cluster Linking Strategy (Critical!)

**Purpose:** Establish topic authority through interconnected content

**Requirements:**

- Link to EVERY cluster article in the topic cluster
- Use descriptive, benefit-driven anchor text
- Place links at natural transition points
- Include brief context for why the link is relevant

**Link Format:**

```
📖 **Deep Dive:** [Benefit-driven description of what's in the linked article]
→ Read the full guide: [Descriptive Anchor Text]
```

**Example:**

```
📖 **Deep Dive:** Wenn du lernen willst, wie du einen Content Audit mit
konkretem Framework durchführst (inkl. Spreadsheet-Template), hab ich einen
kompletten Schritt-für-Schritt-Guide geschrieben:
→ [Content Audit durchführen: 7-Schritte Framework mit Template]
```

**Cluster Link Placement:**

- End of relevant section (primary placement)
- Naturally within content (1-2 contextual mentions)
- In related resources section at end

**Expected cluster links per pillar:** 6-12 links

## Technical SEO for Pillar Pages

### Schema Markup (Required)

**Use schema-generator.xml task**

**Schema Types to Include:**

1. **Article schema** (primary)
2. **BreadcrumbList schema** (for navigation)
3. **FAQPage schema** (if FAQ section included)
4. **HowTo schema** (if step-by-step instructions included)

### Internal Linking Architecture

**Linking FROM Pillar:**

- To ALL cluster articles (6-12 links)
- To related pillars (1-2 links)
- To lead magnets/resources (1-2 links)

**Linking TO Pillar:**

- From ALL cluster articles (with "return to main guide" CTAs)
- From homepage navigation (if top-tier pillar)
- From related content across site

**Anchor Text Strategy:**

- Use varied, descriptive anchor text
- Include target keyword naturally
- Make it benefit-driven

**Example anchors for linking TO pillar:**

- "der komplette Content Marketing Guide"
- "alles über Content Marketing Strategie"
- "von Grundlagen bis Advanced"

---

### Page Performance

**Critical Web Vitals:**

- LCP (Largest Contentful Paint): <2.5s
- FID (First Input Delay): <100ms
- CLS (Cumulative Layout Shift): <0.1

**Optimization:**

- Lazy load images below fold
- Compress images (WebP format)
- Minify CSS/JS
- Use CDN for assets
- Implement caching

**For 5000+ word pages:**

- Consider pagination or "show more" sections
- Implement sticky TOC
- Add "scroll to top" button
- Optimize for mobile (collapsible sections)

---

### Content Refresh Strategy

**Quarterly Review (every 3 months):**

- [ ] Update statistics and data
- [ ] Add new tool recommendations
- [ ] Check for broken links
- [ ] Add new cluster article links
- [ ] Update meta description/title if needed

**Annual Major Update:**

- [ ] Comprehensive content audit
- [ ] Add new sections for emerging trends
- [ ] Refresh all examples
- [ ] Update year in title/content
- [ ] Re-promote as "Updated for [Year]"

**Trigger for immediate update:**

- Algorithm changes affecting SEO advice
- Major tool shutdowns/launches
- Industry shifts making content outdated
- Drop in rankings for target keyword

## Notes for Content-Writer Agent

- Pillar pages take 2-3x longer to create than regular articles
- Prioritize comprehensiveness over speed
- Use interview protocol + research for unique insights
- Don't just aggregate existing content - add original frameworks
- Make it skimmable (headings, bullets, visuals)
- Update cluster links as new articles are published
- This is your SEO crown jewel - invest the time
- Consider breaking creation into phases over multiple sessions
