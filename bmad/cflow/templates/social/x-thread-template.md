# X (Twitter) Thread Template

**Platform:** X (formerly Twitter)
**Format:** Thread (connected posts)
**Character Limit:** 280 characters per post (4,000 for X Premium)
**Purpose:** Thought leadership, viral reach, conversation
**Tone:** Direct, conversational, punchy

---

## Thread Structure

### Thread Length

**Optimal:** 5-12 tweets

- Too short (<5): Not enough depth
- Too long (>15): Reader fatigue

**Thread Purpose by Length:**

- 5-7 tweets: Quick insight or tip
- 8-12 tweets: Framework or deep-dive
- 13-15 tweets: Comprehensive guide or story

---

## Tweet 1: Hook (Critical!)

**Purpose:** Stop the scroll, promise value

**Character Limit:** 280 characters
**Must Include:** Clear value proposition

### Hook Formats

**Format 1: Contrarian Take**

```
Everyone says [common advice].

They're wrong.

Here's what actually works:

[Thread emoji] 👇
```

**Format 2: Bold Claim + Proof**

```
I [achieved impressive result] in [timeframe].

Without [common method people use].

Here's the exact system I used:
```

**Format 3: Pain Point + Promise**

```
[X%] of [audience] struggle with [problem].

I spent [time] solving this.

Here's what I learned (thread):
```

**Format 4: Story Opening**

```
Last [time period], [dramatic event happened].

It taught me [powerful lesson].

Story + lessons in this thread 👇
```

**Format 5: Curiosity Gap**

```
I analyzed [number] [things].

The patterns were surprising.

Here's what I found:
```

### Hook Examples

```
✅ "Most creators are publishing too much content.

I went from 5 posts/week to 2 posts/week.

Engagement tripled.

Here's why: 🧵"

✅ "I made $50K with a 200-person email list.

No ads. No big following.

The strategy: 👇"

✅ "Your content isn't bad.

Your distribution is.

Here's the framework I use to get 10x the reach with the same content:"

❌ "In this thread I'm going to talk about content marketing strategies..."
(Too generic, no hook)
```

**Hook Best Practices:**

- Start with surprising statement or result
- Use numbers for credibility
- Promise specific value
- End with thread emoji (🧵 👇 ⬇️)
- Keep under 280 characters

### Content Tweet Guidelines

**Character Management:**

- Aim for 200-250 characters per tweet
- Leaves room for readability
- Allows for quoted retweets

**Formatting:**

- Use line breaks for readability
- Bullet points (•) for lists
- Numbers for sequences
- → for sub-points or emphasis

**Example Tweet:**

```
Step 3: The Interview Method

Instead of prompting AI:

• Record voice memos answering questions
• Transcribe with Whisper/Otter
• Edit for clarity (not perfection)

Result: Content that sounds like YOU, not ChatGPT.

Takes 30 min. Worth it.
```

**Engagement Hooks Within Thread:**

- Ask mini-questions ("Sound familiar?")
- Use emojis sparingly (1-2 per tweet max)
- Include surprising stats or quotes
- Add concrete examples
- Show before/after

## Thread Alternatives & Formats

### Mini Thread (3-5 Tweets)

**Use for:** Quick tips, hot takes, simple insights

**Structure:**

```
Tweet 1: Hook
Tweet 2-3: Content
Tweet 4: CTA

Example:
1. "Content repurposing isn't copying. It's smart distribution. Here's the difference:"
2. "Copying: Post the same thing everywhere. Lazy. Low engagement."
3. "Repurposing: Adapt format and tone for each platform. Smart. High ROI. One article becomes: • Newsletter • LinkedIn post • X thread • Instagram carousel Each optimized for its platform."
4. "Follow @handle for more content strategy tips."
```

### Mega Thread (15-20 Tweets)

**Use for:** Comprehensive guides, long-form stories, detailed frameworks

**Structure:**

```
Tweet 1: Hook
Tweets 2-3: Setup
Tweets 4-17: Deep content (with sub-sections)
Tweet 18: Summary
Tweet 19-20: CTA

Tip: Number your tweets (1/20, 2/20...) for mega threads
```

## Thread Formatting Best Practices

### Line Breaks

```
✅ Good:
"Use line breaks.

They make your tweets easier to read.

And improve engagement."

❌ Bad:
"Don't write long sentences without breaks because it's hard to read and people will scroll past your content without engaging with it."
```

### Bullet Points

```
Use • or → for lists:

Here's what works:
• Point 1
• Point 2
• Point 3

Or use arrows for flow:
→ Step 1
→ Step 2
→ Step 3
```

### Numbers & Data

```
Use specific numbers:

✅ "I grew from 200 to 5,000 followers in 4 months"
❌ "I grew my followers a lot"

✅ "47% open rate on my newsletter"
❌ "Good open rate on my newsletter"
```

### Emojis

```
Use sparingly (1-2 per tweet max):

✅ "Here's the framework: 🧵"
✅ "Step 3: The Interview Method 🎤"
❌ "Here's 🔥 the BEST 💯 framework 🚀 ever 💪"
```

## Technical Tips

### Threading

- Reply to your own tweets to create thread
- Use Twitter's thread composer for easier drafting
- Can edit tweets within 30 min (X Premium)
- Use Typefully or Thread Reader for drafting

### Timing

- Best times: 9-11am, 1-3pm, 8-10pm (test your audience)
- Best days: Tuesday-Thursday
- Avoid weekends for professional content
- Consistency > perfect timing

### Engagement Tactics

- Pin high-performing threads to profile
- Quote retweet your thread with "This one did well, here's why:"
- Engage with replies quickly (first 30 min critical)
- Repost successful threads after 3-6 months
- Turn threads into carousels for LinkedIn

• Some traffic

• Content expansion (to 2,000+ words)

Less content. Better results.

Google rewards topical authority.

50 great articles > 200 mediocre ones.

You show expertise through depth, not breadth.

• Audit your content

• Delete the dead weight
