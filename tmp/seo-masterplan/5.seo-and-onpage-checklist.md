⚙️ Kapitel 5: Technisches SEO & Onpage-Checkliste (Webflow-Optimiert)

Ziel: Dieses Kapitel stellt sicher, dass alle technischen und strukturellen SEO-Best Practices in Webflow umgesetzt werden können – automatisch überprüfbar durch deine KI-Agenten oder n8n-Flows.

Es enthält sowohl eine Checkliste, die du oder dein KI-Orchestrator (z. B. über n8n) abarbeiten können,
als auch empfohlene Standards für Webflow-spezifische Strukturen (CMS, Meta, Schema, Sitemap, Performance).

⸻

🧩 1. Technische SEO-Grundstruktur

Element Empfehlung Anmerkung
Domain https://adriangoldner.com (nur eine Version, ohne www) Redirects auf non-www erzwingen
SSL / HTTPS aktiv Pflicht für Crawling & Trust
Canonical Tags automatisch per Template in Webflow generieren für alle Collection Items
Robots.txt ✅ vorhanden enthält Sitemap-Link, keine Blockierungen

hreflang nur de-DE notwendig da rein deutschsprachig

Structured Data JSON-LD Schema für Articles, Products & FAQ Automatisch generieren lassen (Template siehe unten)

⚙️ 2. Performance & Core Web Vitals (CWV)

Metrik Zielwert Maßnahmen (Webflow)
LCP (Largest Contentful Paint) < 2,5 s Lazy Loading aktivieren, Bilder komprimieren, CDN nutzen
CLS (Cumulative Layout Shift) < 0,1 keine Layoutsprünge bei Fonts oder Bildern
FID / INP (Interactivity) < 100 ms keine blockierenden Scripts, Formulare async laden
Bilder WebP / AVIF max. 150 KB je Datei
Fonts Systemfonts oder lokal gehostet Vermeide FOUT (Flash of Unstyled Text)
Caching über Webflow CDN automatisch aktiv zusätzlich Browser-Caching aktivieren
Testing Pagespeed Insights + Lighthouse 1× pro Monat testen (n8n-Report)

🔍 3. Onpage-SEO Checkliste

Diese Liste kann direkt von einem KI-Agenten oder n8n-Workflow automatisiert geprüft werden.
(→ z. B. “SEO Validator Agent” checkt pro veröffentlichtem Artikel die folgenden Kriterien)

Kategorie Prüfkriterium Ziel / Regel Automatisierbar
Metadaten Title vorhanden 55–65 Zeichen, Hauptkeyword am Anfang ✅
Description vorhanden 140–155 Zeichen, mit CTA ✅
Slug optimiert nur Kleinbuchstaben, Bindestriche, Keyword enthalten ✅
Headings 1× H1 exakt ein Haupttitel ✅
3–5× H2 Struktur spiegelt Outline wider ✅
1–2× H3 optional für Unterpunkte ✅
Interne Links mind. 2 vorhanden 1 zu Pillar, 1 zu Cluster ✅
Alt-Tags alle Bilder haben beschreibende Alt-Tags Keyword oder Funktion nennen ✅
CTA-Blöcke min. 1 CTA im Text zu Lead-Magnet / Trial / Produkt ✅
Lesbarkeit Ø Satzlänge < 17 Wörter KI-Agent “Readability” testet Text ✅
Keyword Density 0,8–1,5 % Keyword ≈ 5× pro 1000 Wörter ✅
Content-Länge > 1000 Wörter (Cluster), > 2500 (Pillar) Mindestlänge prüfen ✅
Schema Article / FAQ / Breadcrumb JSON-LD implementiert ✅
Bildgrößen max. 150 KB via Webflow Upload prüfen ✅

{
"@context": "https://schema.org",
"@type": "Article",
"headline": "{{title}}",
"description": "{{meta_description}}",
"author": {
"@type": "Person",
"name": "Adrian Goldner"
},
"publisher": {

"@type": "ImageObject",

},
"datePublished": "{{publish_date}}",

}

{

🧩 7. Technische SEO QA-Workflow (empfohlene Automatisierung)

Workflow-ID: seo_qa_webflow_publish
Trigger: Webflow CMS → „New item published“
Actions: 1. Fetch Page Data (API) 2. Validate SEO Fields (Title, Meta, Alt, Internal Links) 3. Parse HTML → check H1/H2 structure 4. Check Schema presence 5. Ping Plausible for baseline metrics 6. Generate short QA report → Telegram + Notion Log

Ergebnis:
🔹 Jede neu veröffentlichte Seite wird automatisch geprüft.
🔹 Der SEO QA Agent gibt ein Go oder markiert fehlende Felder.
