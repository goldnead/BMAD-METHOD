# SEO Article Template

**Format:** Web/Blog (HTML/Markdown)
**Length:** 1500-3000 words
**Tone:** Authoritative yet conversational, educational

---

## Article Structure

### 1. SEO Meta Data (Required)

#### Meta Title (50-60 characters)

**Format:** [Primary Keyword] + [Modifier/Benefit]

**Examples:**

- "Content Interview Methode: Authentischer Content in 2025"
- "SEO Topic Cluster Strategie – Der komplette Guide"

**Rules:**

- Include primary keyword near the beginning
- Stay under 60 characters (optimal: 50-55)
- Make it click-worthy but not clickbait
- Include year if content is time-sensitive

#### Meta Description (150-160 characters)

**Format:** [Problem/Hook] + [Solution] + [CTA/Benefit]

**Example:**
"Schluss mit generischem AI-Content. Die Interview-Methode hilft dir, authentische Artikel zu erstellen, die wie DU klingen. Inkl. Framework + Template."

**Rules:**

- Include primary keyword naturally
- Make it actionable
- 150-160 characters optimal
- No keyword stuffing

#### Focus Keyword

**Primary:** 1 main keyword (e.g., "Content Interview Methode")
**Secondary:** 2-3 related keywords (e.g., "authentischer Content", "Interview-basierte Content-Erstellung")

#### URL Slug

**Format:** `/blog/{primary-keyword-slug}`

**Example:** `/blog/content-interview-methode`

**Rules:**

- Lowercase, hyphens for spaces
- No stop words (der, die, das) unless necessary
- Under 5 words ideal
- Avoid dates in slug (ages badly)

---

### 2. Hero Section

#### H1 Title (Required)

**Similar to meta title but can be longer (60-70 characters)**

**Example:**

```
# Die Content Interview Methode: Authentische Artikel statt AI-Einheitsbrei
```

**Rules:**

- Only ONE H1 per article
- Include primary keyword
- Benefit-oriented or curiosity-driven
- Can differ slightly from meta title for readability

#### Featured Image

**Requirements:**

- Dimensions: 1200x630px (2:1 ratio)
- Format: JPG or WebP
- File size: <200KB
- Alt text: Descriptive with keyword
- Caption: Optional

#### Intro Paragraph (150-250 words)

**Purpose:** Hook reader + establish credibility + outline what they'll learn

**Structure:**

```
[Problem/Pain Point]
  ↓
[Why this matters / Stakes]
  ↓
[Your unique angle / Promise]
  ↓
[What reader will learn]
```

**Example:**

```
Die meisten Content Creators haben ein Problem: Sie wollen authentisch klingen,
aber ihre AI-Tools spucken generische Marketing-Texte aus.

Das Ergebnis? Content der zwar SEO-optimiert ist, aber nach "AI-Einheitsbrei"
schmeckt. Leser merken das sofort – und bounced.

Ich hab das letzten Jahr selbst erlebt. Trotz optimierter Keywords flopped mein
Content. Bis ich die Content Interview Methode entwickelt hab.

In diesem Guide zeige ich dir:
- Wie Interview-basierte Content-Erstellung funktioniert
- Warum diese Methode 3x authentischere Artikel liefert
- Ein step-by-step Framework das du heute umsetzen kannst

Lass uns direkt loslegen.
```

**Intro Checklist:**

- [ ] Opens with reader's problem (not "In diesem Artikel...")
- [ ] Personal hook (story, statistic, or observation)
- [ ] Clear promise of what they'll learn
- [ ] Teases unique insight or contrarian angle
- [ ] Primary keyword mentioned naturally
- [ ] Smooth transition to first section

### 3. Table of Contents (Optional but recommended for 1500+ words)

**Auto-generated from H2 headings**

**Example:**

```
## Inhalt

1. [Was ist die Content Interview Methode?](#was-ist)
2. [Warum traditioneller Content-Prozess scheitert](#warum-scheitert)
3. [Das 5-Stufen Interview Framework](#framework)
4. [Praktische Implementierung](#implementierung)
5. [Häufige Fehler vermeiden](#fehler)
```

**Rules:**

- Only include if 5+ H2 sections
- Link to anchor IDs
- Keep labels concise

### 4. Main Content Body

#### Content Hierarchy

```
H1: Article Title (once only)
├── H2: Major sections (4-7 sections)
│   ├── H3: Subsections (2-4 per H2)
│   │   └── H4: Micro-topics (use sparingly)
```

#### Recommended H2 Sections (adapt to topic):

**1. Introduction/Context Section (H2)**

- What is [topic]?
- Why does this matter?
- Brief history/background if relevant

**2. Problem/Challenge Section (H2)**

- What problem does this solve?
- Why existing solutions fail
- Stakes if not addressed

**3. Solution/Framework Section (H2-H3)**

- Your methodology/approach
- Step-by-step breakdown
- Visual framework if applicable

**4. Implementation/How-To Section (H2-H3)**

- Practical application
- Tools/resources needed
- Concrete examples

**5. Advanced Tips/Optimization (H2)**

- Pro-level insights
- Edge cases
- Optimization strategies

**6. Common Mistakes/Troubleshooting (H2)**

- What to avoid
- FAQ-style problem solving
- Reader objections addressed

**7. Conclusion/Next Steps (H2)**

- Summary of key points
- Clear next action
- Related resources

#### Content Writing Guidelines

**Paragraph Length:**

- 2-4 sentences per paragraph
- Max 100 words per paragraph
- Break up dense text with formatting

**Sentence Structure:**

- Mix short and long sentences
- Avoid 3+ clauses in one sentence
- Use active voice (70%+ of sentences)
- Fragment sentences for emphasis. Occasionally.

**Formatting Elements:**

**Lists (use often!):**

```
- Unordered lists for features/tips
- Numbered lists for processes/steps
- Checkboxes for checklists
```

**Bold/Emphasis:**

```
Use **bold** for key concepts and takeaways (but sparingly!)
Use *italics* for subtle emphasis or terms
```

**Callout Boxes:**

```
> 💡 **Pro Tip:** Use callout boxes for high-value asides

> ⚠️ **Achtung:** Warnings or common mistakes

> 📊 **Case Study:** Real examples or data points
```

**Code/Examples:**

```
Use `inline code` for technical terms or short snippets

Use code blocks for:
- Step-by-step instructions
- Templates
- Examples
```

**Visual Elements:**

- Screenshots with annotations (every 500-800 words)
- Diagrams for complex concepts
- Tables for comparisons
- GIFs for processes (optional)

---

#### Content Quality Standards

**Voice & Tone:**

- Educational but not condescending
- Expert but not jargon-heavy
- Friendly but not overly casual
- Confident but admit uncertainty when appropriate

**Examples & Proof:**

- At least 2-3 concrete examples per major section
- Use real names/companies (anonymize if needed)
- Include data/statistics where relevant
- Personal experience > generic claims

**Keyword Integration:**

**Primary Keyword:**

- In H1 title
- In first paragraph (within first 100 words)
- In 1-2 H2 headings (naturally!)
- 2-4 times in body (0.5-1% density)
- In conclusion

**Secondary Keywords:**

- Naturally throughout content
- In H3 subheadings
- In image alt text
- In internal link anchor text

**❌ AVOID:**

- Keyword stuffing
- Unnatural phrasing for SEO
- Exact-match over-optimization
- Keywords in every heading

---

#### Internal Linking Strategy

**Requirements:**

- 2-4 internal links per article
- Link to relevant published content
- Use descriptive anchor text (not "click here")
- Prioritize links to pillar pages

**Use internal-link-finder.xml task for suggestions**

**Example:**

```
❌ Bad: "Mehr dazu findest du hier."
✅ Good: "Ich hab einen kompletten Guide zu Topic Cluster SEO geschrieben."
```

**Placement:**

- First internal link: Within first 500 words
- Additional links: Naturally throughout
- Avoid link clusters (3+ links in one paragraph)

---

#### External Linking

**Authority Links (2-4 per article):**

- Link to studies, statistics, tools
- Use nofollow for untrusted sources
- Open in new tab (target="\_blank")
- Keep relevant and current (<2 years old)

**Examples:**

- Research papers
- Official documentation
- Industry reports
- Tool websites

### 5. Conclusion Section (Required)

**Length:** 150-300 words

**Structure:**

```
[Recap key takeaways - 3-5 bullets]
  ↓
[Restate main benefit/transformation]
  ↓
[Clear next action]
  ↓
[Optional: Open loop to related content]
```

**Example:**

```
## Fazit: Authentizität schlägt Perfektion

Die Content Interview Methode löst das zentrale Problem von AI-Content:

- ✅ Du behältst deine persönliche Stimme
- ✅ Content basiert auf echten Erfahrungen (nicht generischen Prompts)
- ✅ Leser spüren den Unterschied – und bleiben

Der nächste Schritt? Starte mit einem Interview-Protokoll für deinen nächsten
Artikel. Du brauchst keine fancy Tools – ein Google Doc und 30 Minuten reichen.

Wenn du tiefer einsteigen willst: Ich hab ein komplettes ContentFlow-System
gebaut, das den ganzen Prozess automatisiert. [Link zu relevanter Resource]

Viel Erfolg beim Ausprobieren!
```

**Conclusion Checklist:**

- [ ] Summarizes key takeaways (not a copy-paste)
- [ ] Restates transformation/benefit
- [ ] One clear next action
- [ ] Conversational close (not corporate)
- [ ] Optional CTA to related content or offer

## Notes for Content-Writer Agent

- Prioritize reader value over SEO optimization
- Use interview protocol as primary source (not generic research)
- Maintain authentic voice per tone-of-voice-guide
- Don't force keywords where they don't fit naturally
- Add personal stories and examples (from interview!)
- Break up text frequently (readers skim)
- Make it scannable: headings, bullets, bold, whitespace
- When in doubt: shorter paragraphs, simpler words, more examples
