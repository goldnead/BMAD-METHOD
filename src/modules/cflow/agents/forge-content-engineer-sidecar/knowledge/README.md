## Quick Reference

### Content Engineering Framework

| Format            | Structure Focus       | SEO Priority | Conversion Goal    | Performance Metrics             |
| ----------------- | --------------------- | ------------ | ------------------ | ------------------------------- |
| **Newsletter**    | Engagement flow       | Medium       | Click-through rate | Open rate, CTR, conversions     |
| **SEO Article**   | Information hierarchy | High         | Organic traffic    | Rankings, traffic, dwell time   |
| **Social Media**  | Platform-native       | Low          | Engagement         | Likes, shares, comments, reach  |
| **Content Brief** | Actionable insights   | High         | Content quality    | Content performance, efficiency |

### Multi-Format Transformation Patterns

1. **Interview → Newsletter** - Story + personal insights + soft CTA
2. **Interview → SEO Article** - Structured info + keywords + internal links
3. **SEO Article → Social** - Key takeaways + engaging visuals + hashtags
4. **Newsletter → SEO** - Expanded content + research depth + keyword optimization
5. **Any Format → Brief** - Core insights + action items + next steps

### SEO Structure Requirements

- **H1-H6 Hierarchy** - Logical heading structure for crawlers
- **Keyword Integration** - Primary keyword in H1, secondary in subheadings
- **Internal Linking** - 2-5 relevant internal links per article
- **Meta Information** - Title, description, structured data
- **Content Length** - 1500-2500 words for comprehensive coverage
- **Readability** - Short sentences, clear paragraphs, formatting

### Newsletter Engineering Standards

- **Subject Line** - Personalized, curiosity-driven, mobile-optimized (<50 chars)
- **Preheader** - Complements subject, adds value context
- **Opening** - Personal greeting, engaging hook, value proposition
- **Body** - Scannable structure, clear sections, call-to-actions
- **Closing** - Professional sign-off, next step, brand consistency
- **Design** - Mobile-first, alt-text, loading optimization

### CTA Selection Framework

| Funnel Stage      | CTA Type     | Goal       | Example Language             |
| ----------------- | ------------ | ---------- | ---------------------------- |
| **Awareness**     | Learn more   | Education  | "Discover the full strategy" |
| **Consideration** | Compare      | Evaluation | "See how it works"           |
| **Decision**      | Try/Purchase | Conversion | "Start your free trial"      |
| **Retention**     | Engage       | Loyalty    | "Join the community"         |

### Template Engineering Patterns

1. **Variable Injection** - `{interview_insight}`, `{seo_keyword}`, `{cta_text}`
2. **Conditional Logic** - Show/hide sections based on content type
3. **Format Adapters** - Single template, multiple output formats
4. **Performance Integration** - A/B test frameworks, optimization loops
5. **Quality Gates** - SEO checks, readability scores, conversion potential
